# Examples

**Synthetic smoke-test material, not paper results.**

- `example_config.yaml` — a minimal single-run config. Run it with:

  ```bash
  python scripts/run_experiment.py --config examples/example_config.yaml --stage sweep --out outputs/example
  ```

- `synthetic_data/example_episodes.json` — a tiny batch of synthetic episodes produced by
  `masgym.data.synthetic.generate_episodes`, provided so you can see the trace/metric schema
  without running anything. It is generated by `python scripts/run_synthetic_demo.py` and the
  helper in this folder; it contains **no real benchmark data**.

To generate real-data episodes, wire the adapters in `masgym.data.adapters` and
`masgym.baselines.external_wrappers` to your provisioned datasets/models on EC2
(see `docs/ec2_experiment_guide.md`).
